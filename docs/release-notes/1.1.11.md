# ModelDeck 1.1.11

This release fixes what the 1.1.10 update looked like on a busy machine: the deck said "Daemon unreachable" while the daemon was alive, and a Codex profile migration warning that never went away. It also drops a line from every deck card that nobody used.

**The deck no longer calls a slow daemon unreachable.** The app gave the daemon 5 seconds to answer and treated anything slower as dead, so every card went stale and the banner said unreachable. Data reads now get 60 seconds, a separate health check decides whether the daemon is actually down, and while it is only slow the deck shows one gray line, "Daemon busy · showing data from N min ago", with the last data still on the cards. (#660)

**Daemon reads stay fast on large databases.** Quarantined telemetry that Claude desktop pushes a few hundred records a minute had grown to 1.6 GB with no cleanup, and the usage read walked half a million rows on every refresh. The daemon now prunes the quarantine to 7 days, reads usage per account, and keeps a larger page cache. On a copy of a 2.5 GB database the usage read went from about a second to under a millisecond. (#658)

**Codex profile migration is no longer blocked by the ChatGPT app.** The 1.1.10 migration refused to run while any process named `codex` was running, and the ChatGPT desktop app bundles one. The check now only defers for a codex process that is actually using the old profile folder. If you keep ChatGPT open you may need to quit it fully and relaunch it once after updating, then restart ModelDeck. (#659)

**The "Est. dry" line is gone from deck cards.** It took a row on every card and never said anything useful. The estimate code is removed, not hidden. (#665)

**A deck card says when its proxy sign-in is dead.** When the proxy marks an account's login as unusable, the card shows it directly and the repair step names which subscription to sign in again, instead of leaving you to work it out from a stale card. (#542)
