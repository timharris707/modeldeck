# ModelDeck 1.1.12

One fix, released the same day it was confirmed: Grok subscriptions now work.

**Adding a Grok subscription no longer fails with "sign in explicitly".** Two users on GitHub reported that the Grok card always showed a sign-in error, even seconds after a fresh `grok login` while the Grok CLI itself worked fine. They read the source and found why, and they were right: ModelDeck's credential reader had been written against a guessed layout of the Grok credentials file, and the real file is laid out differently. The billing reply from Grok's servers also nests the usage percent one level deeper than the parser looked. Both readers now match what the current Grok Build CLI actually writes and returns. If you tried Grok before and gave up, remove the subscription and add it again. (public #9)

Thanks to DenXio101 and ccallahan2323 for the report, the diagnosis, and the field names.
