# ModelDeck 1.1.18

A fix release: a failed automatic sign-in renewal now says so, and Codex cards stop listing windows you never use.

**A failed automatic renewal is no longer silent.** When ModelDeck tries to renew an expired Claude sign-in and cannot, it now writes one log line saying why, keeps that reason with the account, and shows it in Settings. If the Mac cannot reach Anthropic (a DNS or network outage), that attempt no longer counts against the six-per-day renewal allowance; ModelDeck retries every 30 minutes until the network is back. After two failures in a row the deck card stops saying "Idle — renews on next use" and says "Renewal failed — sign in needed", with the same one-click sign-in. On 2026-09-22 a three-hour DNS outage left six accounts signed out for half a day with no visible cause; this is the fix. (#724)

**Codex cards show the weekly window and a 5-hour window, nothing else.** Codex also reports per-model windows (GPT-5.3-Codex-Spark, gpt-reserve) that have read 0% used on every account since July and filled the expanded card with "Starts on first use" rows. Those now stay hidden until they carry real usage. Claude cards are unchanged. (#728)

Rollback floor: unchanged
