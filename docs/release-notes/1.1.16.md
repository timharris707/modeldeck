# ModelDeck 1.1.16

Updates get a proper home in Settings, and the Codex profile move finally finishes.

**The Codex profile move now completes while ChatGPT is open.** The deck line "Codex profile move is waiting on codex" has been sitting there for anyone who keeps the ChatGPT desktop app running, because ChatGPT and its helpers hold the old profile folder open all day and the move waited for a quiet moment that never came. When the old folder and ModelDeck's data folder are on the same disk, the background service now renames the folder in one step and leaves a link at the old path, so open files keep working and nothing is copied. The line disappears on its own after this update starts; there is nothing to click. Installs where the two folders are on different disks keep the previous behavior. (#693)

**Settings shows when updates were last checked, and Release Notes always opens.** The app-update section now shows the date and time of the last check, and the Release Notes button opens the notes for the version you are running whether or not an update is waiting. Version, last check, the two toggles, and the buttons live in one section. (#704)

**Beta Releases.** A new toggle in Settings, off by default, lets you receive beta builds before they become stable releases. Turn it off again and you stay on the beta you have until the next stable release is newer than it; nothing is downgraded. (#705)

**Rollback to the previous version, and Get Previous Builds.** Settings gains a Get Previous Builds button that opens the releases page, and a Rollback button that puts the previous release back. Rollback downloads the earlier build, checks its signature and its contents, swaps it into place with a backup kept beside it, and relaunches; the version you left is then hidden from update checks until you check for updates yourself. The Rollback button only appears once there is a later release to roll back from, so it will first show up after 1.1.17 ships. (#706)

**Also**
- Telemetry metrics and events are now kept for 13 months and pruned daily, and the database hands freed space back to the disk instead of holding on to it. (#701)
- Internal: the menu-bar pixel test is adjusted for macOS 27. (#699)

Rollback floor: unchanged
