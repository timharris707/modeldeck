# ModelDeck 1.1.22

Accounts on Anthropic's renamed Ultra plan, formerly Max 20x, keep their plan label and top priority once Claude starts reporting the new name. Until then they read "Max (20x)" as before.

ModelDeck now warns when the proxy is set to discard usage records before ModelDeck reads them. New proxies set up by the app keep unread records for an hour.

Groundwork for sharing one proxy pool between Macs: a Mac can use another Mac's pool without touching its own sign-ins, the pool Mac hands each machine its own key, and the deck links to the pool Mac's usage page. Nothing changes until a Mac is set up this way.

The bundled CLIProxyAPI moves to 8.0.47, with fixes for a log filename path escape, resource exhaustion from incomplete or oversized requests, and Claude 5.5 forced tool use. Updating ModelDeck does not replace a separately managed proxy.

Rollback floor: unchanged
