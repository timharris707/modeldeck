# ModelDeck 1.1.19

A fix release: the deck window now fits its cards as you expand and collapse them, in the menu bar and in the floating window, and the bundled proxy catches up with current Claude Code and Codex.

**Expanding and collapsing cards no longer leaves blank space or cuts the deck off.** In 1.1.18, collapsing cards left an empty band above and below the menu-bar deck. Expanding a card could cut off the deck's header and footer, and in the floating window nothing could be scrolled back into view. The deck now sizes its own window as cards open and close, keeping the top edge in place. A deck taller than the screen scrolls its cards while the header and footer stay put, and a floating window that grows past the bottom of the screen moves up. Both windows were checked on a real screen before this release. (#738, #719)

**The bundled proxy moves from v7.2.149 to v7.3.20.** It now presents itself as current Claude Code (2.1.280) and Codex (0.155.0) clients. It also names Claude sign-in files differently, so two organizations under one email stay separate; ModelDeck reads sign-ins by what is inside them, so old and new names both work. This only affects the proxy ModelDeck runs for you. A proxy you run yourself is not touched. (#740)

Rollback floor: unchanged
