# ModelDeck 1.1.17

A fix release: the deck window sizes itself correctly again, a provider outage no longer looks like a dead login, expanded Codex rows keep their names readable, and the release build can never touch your real Codex profiles.

**The deck no longer keeps a gap at the top with square corners.** After 1.1.16 first launched, it showed the tall "Background service starting…" card and then cleared it, but the deck window kept its taller size. The content sat centered in the oversized window, which read as a blank band at the top and lost the rounded corners. The deck now shrinks its window back to fit whenever its content gets shorter, keeping the top edge attached to the menu bar. Growth is unchanged, and the floating deck window is never resized. (#719)

**A provider overload no longer reads as an expired sign-in.** When a provider answers "servers overloaded", the proxy pool marks that login unavailable for a while. The deck card and the Settings row called that "Proxy sign-in expired" and promoted the Fix sign-in button, even though the login was fine. They now say "Provider overloaded · proxy retrying" and offer no repair; a real dead login still gets the sign-in button. (#714)

**Expanded Codex rows keep their window name.** A window with no usage yet this period used to say "Resets 7 days after first use" on the right, long enough to squeeze the name on the left down to "Weekly ·…". It now says "Starts on first use"; the length of the window is already in its name and in the hover text. (#725)

**Internal: the release build can no longer reach the operator's real profiles.** The daemon's build-time health check now runs under a scratch home folder with every home-derived path pointed inside it, and the Codex profile move refuses to touch a folder that no registered subscription points at. Both carry tests that fail on the previous code. (#717)

Rollback floor: unchanged
